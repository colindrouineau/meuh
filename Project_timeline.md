La demande du client était de mettre en place un "Outil de traçabilité et qualité multi-sites pour des fermes laitières".

Au départ, nous avons tenté de créer une application mobile, mais nous nous sommes vite rendu compte qu'on aurait de toute façon besoin d'une interface ordinateur, notamment du côté de RESAN pour manipuler la base de données. En réalité, on aurait très bien pu satisfaire la demande avec une app, mais le site internet était plus facile à mettre en place.

La première étape de la réalisation du site était de comprendre précisément le besoin de RESAN, d'intégrer le vocabulaire, de visualiser le type d'informations à transmettre.
Ensuite, avant de commencer à coder, il fallait établir le plan théorique du site.
Puis on a commencé à coder. La répartition (en réalité plus poreuse) s'est faite par type de code :
Elisa a travaillé sur la partie front end/back end de la base de données et sur l'organisation du site avec Flask
Cyrianne a travaillé sur les fichiers HTML, CSS et Javascript.
Colin s'est occupé de la partie du code qui assure la communication avec RESAN (par l'envoi par mail du fichier excell), ainsi que de la mise au propre de l'architecture du code (avec le readme, la license, la project_timeline).
